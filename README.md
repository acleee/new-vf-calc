# new-vf-calc
Sound Voltex B50 Calculator using Exceed Gear VF only.

Chart levels are truncated to whole numbers, ULTIMATE CHAIN uses a 1.05 multiplier,
and all MAXXIVE CLEAR lamps count and display as EXCESSIVE CLEAR (1.02).

https://whiteou7.github.io/new-vf-calc/

Supported methods:
- Kamaitachi
- Unnamed SDVX Clone (USC) maps.db
